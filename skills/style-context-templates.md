## 模板 A · 浅暖 Modern Tech（LangGraph 系列）

> 实现 skill：`modern-tech-explainer`(含 graph 全家桶 + Shiki 代码高亮 + e2e 示例)。完整风格语法见该 skill 的 references/style-guide.md,此处只取定调所需的最小集合。

```
### 主题定位
精致克制的现代 tech 质感。参照 Linear / Vercel / Arc / Raycast。
情绪坐标：精致 · 克制 · 现代。不做：赛博朋克、卡通、教科书、AI 紫粉渐变。

### 色板
| 用途 | 色值 | 说明 |
|---|---|---|
| 主背景 | #f5efe4 | 浅暖米色，90% 场景的底 |
| 深色背景 | #1a1917 | 代码块 / 编辑器 / 严肃对比 |
| 卡片背景 | #ffffff | 纯白，少数场景 |
| 主文本 | #1a1917 | 标题、正文 |
| 弱文本 | #4a453e | 副标、注释 |
| 极弱文本 | #8a8478 | 元数据、行号 |
| 品牌金 | #c47a3a | 强调、光效、章节序号 |
| 金色柔光 | #d4a574 | 品牌金次级 |
| 金色发光 | #e8c48a | glow 效果 |
| 线条主色 | #2a2620 | 描边、边框 |
| 线条弱 | rgba(26,25,23,0.15) | 分隔线 |

每 scene 至多 3 个前景色。品牌金只用于强调，不做大面积背景。
深色背景只在讲代码/系统内部时使用。

### 字体
| 用途 | 字体 | 大小 |
|---|---|---|
| 大标题 | IBM Plex Sans Bold / PingFang SC Bold | 72-96px |
| 正标题 | IBM Plex Sans SemiBold | 40-56px |
| 副标/说明 | IBM Plex Sans Regular / PingFang SC | 24-32px |
| 正文 | PingFang SC | 24-28px |
| 代码/序号 | IBM Plex Mono / JetBrains Mono | 20-24px |
| 字幕 | PingFang SC Medium | 42-48px |

一屏内 Bold ≤ 2 个。中文标题用 PingFang SC 不用 IBM Plex。
Mono 只用于代码/数字/序号。

### 卡片
三种规格：
- 大卡片 1100×620，圆角 32px，无描边，多层柔阴影
- 中卡片 520×300，圆角 24px，无描边，多层柔阴影（弱）
- 小卡片 320×180，圆角 16px，hairline 1px rgba(0,0,0,0.05)，单层柔阴影

多层柔阴影配方：
  0 1px 2px rgba(0,0,0,0.04),
  0 8px 24px rgba(0,0,0,0.08),
  0 24px 64px rgba(0,0,0,0.12)

卡片内部细节：顶部 1px 高光 + 微渐变底色（顶亮 3% → 底暗 3%）+ 右上径向高光。

### 图节点
- 普通节点：圆角矩形 16px，200×80，白底 2px #2a2620 描边
- 决策节点：菱形 160×160
- 特殊节点：圆角矩形 + 双描边

### 动画节奏
- 元素入场：spring(damping 12, stiffness 90)，400-600ms
- 边绘制：easeOutCubic，300-400ms
- Token 流动：linear，800-1200ms/边
- 场景转场 fade：300ms
- 章节转场：800-1200ms
- 单场景最短停留 1.5s，概念解释 3-5s
- 缓动只用：spring / easeOutCubic / easeInCubic / linear

### 品牌动效（选择性使用）
- 电流扫描：双金色横线 #e8c48a 聚拢，1.2s，仅片头/收束/强调
- 冲击波环：品牌金圆环扩散到 800px，1.2s，每集 ≤ 3 次

### 字幕
底部 120-160px 安全区，PingFang SC Medium 44px，白色 #ffffff，3px 黑描边。
每行 ≤ 22 中文 / 30 英文字符，一屏 ≤ 2 行。

### 禁止项
硬偏移阴影（图节点除外）、粗描边、毛玻璃 heavy blur、大面积渐变背景、
emoji 主视觉、旋转/翻页/百叶窗转场、Comic Sans、AI 紫粉荧光渐变。
```

## 模板 B · 暗底暖金 Dark Botanical（DeepSeek 系列）

> 实现 skill：`dark-botanical-explainer`(含 Primitives/Charts/CodePanel + AI/ML 构件 + e2e 示例)。完整风格语法见该 skill 的 references/style-guide.md,此处只取定调所需的最小集合。

```
### 主题定位
暗底暖金，数据密集型知识视频。深黑底 + 金色/暖色强调，技术克制感。
情绪坐标：沉稳 · 数据感 · 有温度的科技。

### 色板
| 用途 | 色值 | 说明 |
|---|---|---|
| 主背景 | #0f0f0f | 深黑 |
| 卡片背景 | rgba(255,255,255,0.03) | 半透明微白 |
| 正文 | #e8e4df | 主文字 |
| 弱文字 | #9a9590 | 副标题 |
| 极弱文字 | #5a5550 | 标注、来源 |
| 暖金 | #d4a574 | 主强调色，标签、关键词 |
| 哑金 | #c9b896 | 标题、装饰线、核心数字 |
| 红 | #e63946 | 危险、警示 |
| 绿 | #2ec47a | 正向、增长 |
| 青 | #3dc2c2 | 技术类 |
| 橙 | #e8873d | 中性强调 |
| 紫 | #9b59b6 | 特殊类 |
| 边框 | rgba(255,255,255,0.06) | 卡片边框 |

标题统一用哑金。每个技术子模块可有固定配色（按需扩展）。

### 字体
| 用途 | 字体 | 大小 |
|---|---|---|
| 标题/金句 | Noto Serif SC（衬线） | 72-96px |
| 正文/说明 | Noto Sans SC | 26-32px |
| 代码/数据 | JetBrains Mono | 20-24px |

SVG 内文字比 HTML 大 2-4px。图表标注最小 16px。

### 布局
- 所有场景内容垂直居中（justifyContent: center）
- 底部留 ≥ 64px 字幕安全区
- 内容最大宽度 1400-1600px
- 每个场景必加 BotanicalBg 装饰（浮动光圈 + 细竖线）

### 动画节奏
- punch spring: damping 12, stiffness 200, mass 0.8（强调弹入）
- slide spring: damping 15, stiffness 150, mass 1.0（普通滑入）
- 标题先出，副标题延迟 8-12 帧
- 内容元素依次出现，间隔 10-15 帧
- 场景转场 fade 10 帧

### 品牌动效
- 电流扫描：上下两条 80px 光条
- 冲击波：圆环扩散 + strokeWidth 递减
- 文字放大：电流期间 scale 1.0→1.06→1.0

### 图片使用
- Logo 用 filter: invert(1) 反色
- 图片边框用对应模块颜色 + 20% 透明度
- 圆角 12px，阴影 0 0 40px ${color}20 + 0 8px 30px rgba(0,0,0,0.4)
- 图片不超容器 60%

### 禁止项
BotanicalBg 不加 CSS blur、SVG feGaussianBlur stdDeviation ≤ 4、
不要卡通风格、不要过度粒子效果。
```

| 用途 | 色值 | 说明 |
|---|---|---|
| 主背景 BG | #FBF6EA | 米白纸面,全部场景的底 |
| 网格线 GRID | #D8D2C4 | 1.5px 手绘感方格,间距约 80px,整体微旋 -0.4° |
| 描边 INK | #2B2B2B | 统一 3px 粗描边,线端转角圆润 |
| 填充 PALETTE | #5FB8A5 / #7CBF6E / #F4C542 / #F08060 / #7C9FD6 / #DCE6F2 | 青绿/草绿/明黄/珊瑚橙/灰蓝/淡蓝灰,只从这里取填充色 |
| 强调 ACCENT | #1F6F8B / #2D6A4F | 深青蓝/墨绿,仅用于徽章底色 |
| 贴纸边 | 同 BG | 每个元素带 6-8px 外描边,形成贴纸感 |

备选预设「黑板粉笔」:BG #2B2B2B、INK #F5F0E6、粉笔四色,徽章浅底深字。

### 字体
| 用途 | 字体 | 大小 |
|---|---|---|
| 关键词徽章 | PingFang SC 900(超粗) | ≥64px,白字 |
| 大标题 | PingFang SC 900 | 72-96px,INK 色,关键词用 ACCENT 高亮 |
| 字幕 | PingFang SC Medium | 42-48px,底部安全区 |

禁衬线字体。文字颜色只有两种:徽章内白、背景上 INK。

### 组件(五类构件,全部代码绘制)
- 徽章:全圆角 ACCENT 色块 + 超粗白字,承载一切关键词/标题
- 卡片:白底圆角(半径 ≥16px)粗描边容器
- 图形节点:基本几何形拼出的示意图(矩形、圆、椭圆、圆柱、连线方块)
- 连接线:虚线弧线 + 末端实心小三角,strokeDashoffset 缓慢流动
- 背景网格:唯一装饰层
复杂插画(吉祥物、设备 UI)走 AI 素材,规则见 doodle-explainer 的 asset-prompts.md。

### 动画节奏
- 入场:回弹 spring(damping 10-12),scale 0→1 带 overshoot + 短位移,12-18 帧(30fps)
- 静止:±5px 正弦呼吸浮动,各元素相位错开
- 转场:整组水平滑动,新旧重叠约 18 帧,easeOutCubic
- 元素逐个弹入(间隔 6-12 帧),图形先于标签、节点先于连线,已入场元素常驻
- 单场景 3-5s;禁匀速线性动画

### 禁止项
渐变、投影、模糊、3D;细线(<2px)、尖角、衬线字体;匀速动画;元素无故消失;一屏静态排版式出场。
