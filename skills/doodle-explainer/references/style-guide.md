# 风格语法(Style Guide)

写代码前读完本文件。
所有颜色一律引用变量区的 `BG / GRID / INK / PALETTE / ACCENT`,正文和代码中禁止出现硬编码色值。

> **与导演(visual-brief)的边界**:导演定内容/相对布局/节奏/转场,本文件只定"怎么用涂鸦实现"。导演标的场景时长、转场类型、音画偏移,**以导演为准**,本文件给的是实现默认值,不是铁律。

## 变量区结构

### 内容变量

- 主题:如「向量检索」
- 关键词列表:拆出的 3~8 个概念词
- 画幅:默认横屏 1920x1080(FHD),30fps
- 框架:默认 Remotion + TypeScript + rough.js
- 总时长:由导演的场景规划决定(单场景 3~8s,导演标的时长为准;本文件默认 3~5s)
- **音画偏移**:按导演标的偏移在 delay 上加减帧:提前=delay-9帧(0.3s,新概念先于旁白);同步=不变(代码逐行);滞后=delay+6帧(0.2s,否定/stamp/结论晚于旁白)

### 配色变量

**配色一律从 `references/theme-catalog.md` 选主题对象，不在本文件写死色板。** brief 的 themeRef 决定用哪个主题；没写默认 `playful`。

- 默认主题「playful」(手账桃土):`BG=#F0C8A0`,`GRID=#E8B88E`,`INK=#1A1A1A`,`PALETTE=[#F7DEC6, #F0C8A0, #E8B88E]`,`ACCENT=[#1A1A1A]`
- 其他主题(如 retro-zine/scatterbrain/daisy-days/capsule/stencil-tablet):查 `theme-catalog.md` 取 BG/GRID/INK/PALETTE/ACCENT + lineConfig。
- 黑板粉笔(暗底)保留为特殊变体:`BG=#2B2B2B`,`GRID=#4A4A4A`,`INK=#F5F0E6`,`PALETTE=[粉笔黄 #F4D35E, 粉笔蓝 #7FB5D5, 粉笔红 #E88C7D, 粉笔绿 #9BC995]`,`ACCENT=[#F5F0E6]`(徽章改为浅底深字)

自定义色板规则:BG 与 GRID 明度差 10~15%;INK 与 BG 对比度 ≥7:1;PALETTE 给 4~6 个同明度、中低饱和色;ACCENT 给 1~2 个与 BG 强对比色。

### 动效变量(有默认值,一般不改)

- 弹入:spring damping=10~12,12~18 帧完成
- 转场重叠:18 帧(已就位元素保持静止,不呼吸不浮动)

## 设计基调(Token)

- 背景:BG 色纸面 + GRID 色网格线(线宽 1.5px,间距约 80px),轻微手绘感,整体微旋 -0.4°
- 描边:统一 INK 色,粗 3px,线端和转角全部圆润
- 填充:只从 PALETTE 取色
- 徽章:ACCENT 色底,只用于关键词/标题
- 每个元素带 6~8px 与 BG 同色的外描边,形成贴纸感
- 文字:超粗无衬线(fontWeight 900),关键词字号 ≥64px;字色只用 BG 色(徽章内)或 INK 色(背景上)
- **色码贯穿**:同一概念全程用同一 PALETTE 色,不换色。开场为每个核心概念定一个色码(如"输入"=青绿、"失败"=红),后续该概念再出现时用同色。观众靠颜色认概念,中途换色会丢锚点。

## 造型语法(五类内容构件 + 主题 signature 装饰层)

### 五类内容构件的画法语法(承载信息,唯一允许的信息容器)

> **不列组件名清单**——组件是工程资产(`src/components/doodle/`),skill 只定义"画法规则",按规则自由组合,别被清单框住实现。

1. **徽章**(承载关键词/标题):全圆角色块 + 超粗字,ACCENT 色底
2. **卡片**(承载一组相关图形):圆角粗描边容器,可叠内容
3. **图形节点**(承载概念本体):基本几何形(矩形、圆、椭圆、圆柱、连线方块)拼出的示意图
4. **连接线**(表达关系/流向):虚线弧线 + 末端实心小三角
5. **背景网格**(唯一装饰层):BG 色纸面 + GRID 色网格线

画法规则:2D 扁平、大圆角(半径 ≥16px)、纯色填充。
手绘线条克制规整:rough.js `roughness` 0.5~0.8 + 固定 seed,保证逐帧不闪烁。
禁渐变、阴影、3D。
**自由组合**:同一概念可以用任意几何形拼出来(如"数据库"=圆柱+"存储"=方块堆),不必局限于某个固定组件。

### 数据/ML 元素的画法约定(当内容需要时)

按内容语义自由画,给几个常见约定(非清单,可按需扩展):

- 表格/对比表:粗描边手绘网格表,表头 ACCENT 底,逐行弹入,可高亮某行
- 矩阵/热力图:格子矩阵,cell 填充透明度按 |值| 缩放,逐格 reveal
- 向量:一行带值的格子,标维度
- token 序列:一行手绘圆点,active 高亮放大,可画 attention 弧线指向历史 token
- 代码:卡片 + 等宽字体逐行点亮 + ACCENT 高亮条 + 讲完行回落
- 公式:拆成 token 按类型上色(var=PALETTE/num=ACCENT/fn=ACCENT2/op=INK)
- 对话:user 左/assistant 右气泡,粗描边 + 尾巴 + 角色标签
- 放大聚焦:把子元素放大推到中心 + 提层,聚焦后回落
- 粒子聚合:一组粒子先散布,再聚合到目标位(打散/重组/汇聚/拼接)

### 主题 signature 装饰层(只做静态陪衬,不承载信息)

从 `references/theme-catalog.md` 当前主题取 signature 元素(如 scatterbrain 图钉/胶带、retro-zine 颗粒/旋转印章、capsule 药丸装饰、daisy-days 手绘雏菊)。规则:

- **只做静态陪衬**:入场后不动、不参与信息表达、不与信息元素抢焦点
- **归属明确**:挂在角落/背景/卡片边缘,禁止盖在信息元件上
- **密度克制**:每屏 ≤3 处,多了变噪音
- **常见实现**(按主题,非清单):
  - 图钉:小圆(ACCENT 红)+ 小阴影,钉在卡片上角
  - 胶带:半透明浅色斜条(旋转 20~30°),跨卡片一角
  - 颗粒叠层:全屏 SVG noise(opacity 0.07)置于最顶层
  - 旋转印章:rough 圆环 + 文字,旋转 -8°~-15°,静态角落
  - 手绘装饰:雏菊/星星/彩虹(SVG 路径),聚画面角落
  - 药丸装饰:小号 pill 色块,散落背景,低饱和
- 主题没有 signature 就不加,不是每个主题都要有装饰

## AI 素材(交 asset-generation skill)

代码画不动的复杂插画(吉祥物/设备/有机曲线)、截图、Logo——**统一交给 `asset-generation` skill**(传 engine=doodle + themeRef)。判断标准/风格前缀/验收/接入规则都在那边,本文件不内嵌。工作流第 0.5 步先查 `public/` 现成素材,没有再调用。

## 动画语法(运动只有三种)

1. **弹入**(所有入场):回弹 spring,scale 0→1 带 overshoot + translateY 30→0 + 淡入
2. **信息密集推进**(anti-PPT 核心手段):已就位元素保持静止(不呼吸不浮动),靠每 1-2s 新元素入场/状态变化/焦点切换维持活力。不是"让东西一直动",是"让信息一直来"。
3. **转场**(导演标的类型为准,三种实现):
   - **滑动**(推进):整组水平滑出/滑入,缓出曲线
   - **硬切**(紧迫):无过渡动画,直接切换场景
   - **淡入**(换话题):旧场景整体淡出,新场景淡入

细节:虚线用 `strokeDashoffset` 缓慢流动暗示方向;箭头用 `pathLength` 从起点向终点生长。
禁止任何匀速线性动画。
**禁止装饰性运动**(呼吸/浮动/光球/火花/镜头无目的晃动)--对讲解无帮助,是噪音。

## 时序语法(与内容无关的铁律)

- 元素按阅读顺序逐个入场,永不一屏同时出现;相邻元素间隔 6~12 帧
- **入场三层顺序**:外框/容器先(定义空间)-> 核心元素次(填数据)-> 标签/箭头最后(标注关系)
- 节点先于连线(箭头等两端节点就位后才生长)
- 成组元素按行/列交错入场,组内间隔 3~5 帧
- 已入场元素常驻不消失,直到整组转场
- 单场景时长:导演标的为准(3~8s),默认 3~5s

## 禁止项

- 五类内容构件禁止用图片代替,一律代码绘制;复杂插画允许 AI 生成素材,按上文「AI 素材生成」规则(锁色板、去文字、套统一弹入 hook)
- 禁渐变、投影、模糊、3D
- 禁细线(<2px)、尖角、衬线字体
- 禁匀速动画、禁元素无故消失、禁一屏静态排版式出场
- 禁在 theme 文件之外出现任何硬编码颜色值
- 禁装饰性运动(呼吸/浮动/光球/火花/镜头无目的晃动)

## 交付要求

- 配色集中为单一 theme 文件,全部从变量区映射;换主题只改 theme-catalog 条目
- 工程组件见 `src/components/doodle/`,按本文件画法规则使用;不硬套组件清单
- 统一弹入 hook(spring scale+位移+淡入)。已就位元素保持静止,不浮动
- 每个场景渲染关键帧静帧自检:布局居中、文字不裁剪、用色全部来自 PALETTE/ACCENT
- 提供 dev 预览、stills、render 三个脚本
- **布局自检**(渲染静帧后程序化检查):bounding box 不重叠(引线/箭头除外)+ 在安全区内(四周边距≥80px,底部≥54px 字幕区)+ 文字不溢出容器。不通过则报具体碰撞对,定点修后重验
