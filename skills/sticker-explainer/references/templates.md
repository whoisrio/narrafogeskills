# 叙事结构骨架库·贴纸风

模板只定义「布局 + 构件 + 时序**顺序**」,内容槽位用 `{}` 占位。
时序标注的是**入场顺序 + 间隔范围**(如"节点先于连线,间隔 6~12 帧"),不是固定帧号——**真实 cue 时间戳是锚点**,模板只定顺序不定格数。
> **导演优先**:visual-brief 已给相对空间关系/节奏/转场时,以导演为准,模板只是默认骨架。
> **signature 槽位**:每个模板标注"这个布局里主题 signature 放哪"(可选,见 style-guide 装饰层规则)。
> **参考非菜单**:这些是"结构骨架"参考,不是必须选的模板编号——理解结构意图后,可以自由调整布局。
> **画法差异**:与 doodle 骨架库结构一致,但构件全部换硬边(硬边卡片/节点/箭头/硬偏移阴影),见 `style-guide.md`。

## 文案 → 结构骨架选择线索

| 文案中出现的措辞 | 结构骨架 |
| --- | --- |
| 疑问句开头(「为什么」「什么是」「怎么做到的」) | 悬念揭示(问题大字 → 带?节点 → 答案) |
| 「由…组成 / 三个原因 / 分为」 | 概念拆解(顶部概念 → N 张卡片) |
| 「先…然后…最后 / 流程 / 过程 / 步骤」 | 流程管道(节点链 + 箭头生长) |
| 「传统 vs 新 / 对比 / 区别 / 前后」 | 对比(中缝分屏,左右并置) |
| 「海量 / 百万级 / 每秒 N 次 / 每天 N 亿」 | 规模冲击(1 个 → 复制成矩阵) |
| 「应用于 / 生态 / 场景包括 / 都能」 | 概念地图(中心 + 放射关联) |
| 「这段代码 / 逐行 / 函数 / 源码」 | 代码讲解(逐行点亮 + 注释) |

典型整片组合:悬念揭示(开场) → 概念拆解或流程管道(原理) → 规模冲击(规模) → 概念地图(收尾地图)。

## 模板 1:概念拆解(Breakdown)

把一个抽象概念拆成 N 个组成部分。适合「XX 由什么组成」「XX 的三个特性」。

- 布局:顶部 `{概念}` 大徽章 → 中部一行(或一列)N 张卡片,每张 = 图形节点 + 小徽章
- 构件:徽章 ×(N+1)、StickerCard ×N、FlatNode ×N
- 时序顺序(N=3):
  1. 顶部徽章弹入 → 15~25f 后卡片 1 弹入,随后其标签弹入
  2. 卡片 2、3 依此节奏入场(间隔 12~20f)
  3. 全部就位后保持静止
- 变体:N>4 时改为两行网格,行间交错 10~15f
- signature 槽位:卡片组外侧(角上)挂主题装饰,不盖卡片

## 模板 2:流程管道(Pipeline)

表达先后顺序/数据流向。适合「XX 的工作流程」「从 A 到 B 的过程」。

- 布局:横向节点链(节点超过 5 个时折成 Z 字形两行):卡片或图形节点之间用实线折线箭头连接,每节点下方小徽章
- 构件:FlatNode ×N、徽章 ×N、FlatArrow ×(N-1)
- 时序顺序(N=4):
  1. 节点 1 弹入 → 12~18f 后标签弹入
  2. 箭头 1 生长(pathLength 0→1,12~18f 完成)→ 紧接着节点 2 弹入
  3. 之后每 20~30f 推进一格:箭头生长 → 节点弹入 → 标签弹入
  4. 收尾:箭头保持(贴纸风实线,不做虚线流动)
- 变体:环形流程(首尾箭头闭合,最后一条箭头延迟 20~30f 闭合,强调「循环」)
- signature 槽位:节点链下方空白带,放主题装饰(如胶带条/图钉)

## 模板 3:对比(Versus)

两个方案/前后的对比。适合「传统 XX vs 新 XX」「优化前后」。

- 布局:中缝分屏(硬边分割线),左 `{方案A}` 右 `{方案B}`;每侧顶部徽章 + 中部图形节点/卡片;胜出一侧底部加 `{结论}` 徽章(ACCENT 色)
- 构件:徽章 ×3、节点/卡片 ×2~4、中缝分割线 ×1
- 时序顺序:
  1. 中缝分割线从上到下生长
  2. A 侧徽章+节点弹入 → 25~40f 后 B 侧同样入场
  3. 败方整体 opacity → 0.4 + 轻微缩小(0.95),随后结论徽章弹入胜方
- 变体:三方对比改三栏,败方变灰同时做(间隔 8~12f)
- signature 槽位:中缝上下端(分屏交汇处)

## 模板 4:规模冲击(Scale)

表现「海量/爆炸式增长」。适合「海量数据」「每秒 N 次请求」。

- 布局:中央大容器卡片;内部先是 1 个图形节点,随后复制成 M×N 矩阵;底部 `{数量结论}` 大徽章
- 构件:StickerCard ×1、FlatNode ×(M×N)、徽章 ×1
- 时序顺序:
  1. 容器卡片弹入
  2. 第 1 个节点弹入并停顿 12~18f(让观众看清「一个」)
  3. 其余节点按行交错快速弹入(组内间隔 3~6f,行间隔 8~12f),密度形成视觉冲击
  4. 节点全部就位后:底部结论徽章弹入,字号放大到 1.1 倍再弹回
- 变体:矩阵换成「从一点向外扩散」的放射布局,表现「传播」
- signature 槽位:容器卡片四角

## 模板 5:概念地图(Hub & Spoke)

一个核心概念与多个关联概念的关系网。适合「XX 生态」「XX 的应用场景」。

- 布局:中心 = FlatNode + `{核心概念}` 徽章;四周放射排布 N 个 `{关联概念}` 徽章(横屏推荐左右各 2 个),实线箭头从外围指向中心(或反向,表达方向)
- 构件:FlatNode ×1、徽章 ×(N+1)、FlatArrow ×N
- 时序顺序:
  1. 中心节点弹入 → 12~18f 中心徽章弹入
  2. 外围徽章顺时针逐个弹入(间隔 10~15f)
  3. 每个外围徽章入场后 6~10f:对应箭头生长指向中心
- 变体:双层地图(外围徽章再各自带 1~2 个小节点,第二层入场整体顺延 30f)
- signature 槽位:放射区外圈空白,放主题装饰

## 模板 6:悬念揭示(Hook & Reveal)

开头钩子,先问后答。适合视频开场或章节转折。

- 布局:上 1/3 `{悬念问题}` 超大文字(直接写在背景上,不用徽章);中部 FlatNode 带 `{?}` 标记;下 1/3 留白给 `{答案}` 徽章
- 构件:大标题 ×1、FlatNode ×1、徽章 ×1
- 时序顺序:
  1. 问题文字逐词弹入(每词间隔 5~8f,关键词用 ACCENT 色)
  2. FlatNode 弹入,`{?}` 用 scale 1→1.3→1 脉冲两次
  3. 答案徽章从底部弹入并停住,问题文字 opacity 降至 0.3 退为背景
- 变体:答案为多个时,用模板 1 的网格承接,本模板只负责钩子和第一个答案
- signature 槽位:下 1/3 留白边缘

## 模板 7:代码讲解(Code Walk)

逐行讲代码。适合「看这段代码」「这个函数做了什么」「源码里是这么实现的」。

- 布局:中央偏左大卡片承载代码块,等宽字体逐行排;右侧/下方为注释区;当前行用 ACCENT 色高亮条标记,注释徽章用实线箭头指向对应行
- 构件:StickerCard ×1、文本行若干(等宽字体如 JetBrains Mono)、徽章 ×N、FlatArrow ×N、可选 StepBadge 标步骤序号
- 时序顺序(总长由 cue 决定,4~6s 默认):
  1. 代码卡片弹入,全部行以 40% 透明度就位(先让观众看到整体结构)
  2. 按旁白顺序,当前行 opacity→1 + 高亮条从左侧弹入;讲完的行回落到 70%
  3. 需要注释时:注释徽章弹入,随后箭头生长指向该行(节点先于连线)
  4. 任何时刻只有一行处于焦点高亮(守「一个时刻一个焦点」)
- 变体:演示函数可配「输入 → 输出」小徽章在卡片上下方;长代码分页,页间转场按导演标的类型(滑动/硬切/淡入)
- signature 槽位:代码卡右下角(不遮代码)

## 如何新增结构骨架

骨架库是开放集合,发现新的叙事结构就追加。新增骨架必须遵守:

1. 放在本文件末尾,标题格式:`结构骨架 N:名称(英文名)`
2. 必须包含四个部分:一句话适用场景、布局、构件、**时序顺序(入场顺序+间隔范围,不写死帧号)**;变体可选
3. 信息容器只能用 style-guide 的五类内容构件画法,不得引入新**信息**构件类型;主题 signature 装饰层可用(见 style-guide)
4. 时序顺序必须遵守时序语法铁律(逐个弹入、图形先于标签、节点先于连线)
5. 在选择线索表中补充对应的文案措辞特征
6. 时长以导演 cue 为准,骨架不设固定总长
