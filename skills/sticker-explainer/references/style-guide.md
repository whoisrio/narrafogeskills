# 风格语法(Style Guide)·贴纸风

写代码前读完本文件。
所有颜色一律引用变量区的 `BG / GRID / INK / PALETTE / ACCENT`,正文和代码中禁止出现硬编码色值。

> **与导演(visual-brief)的边界**:导演定内容/相对布局/节奏/转场,本文件只定"怎么用贴纸实现"。导演标的场景时长、转场类型、音画偏移,**以导演为准**,本文件给的是实现默认值,不是铁律。

## 变量区结构

### 内容变量

- 主题:如「向量检索」
- 关键词列表:拆出的 3~8 个概念词
- 画幅:默认横屏 1920x1080(FHD),30fps
- 框架:默认 Remotion + TypeScript(无 rough.js,纯 CSS/SVG 硬边)
- 总时长:由导演的场景规划决定(单场景 3~8s,导演标的时长为准;本文件默认 3~5s)
- **音画偏移**:按导演标的偏移在 delay 上加减帧:提前=delay-9帧(0.3s,新概念先于旁白);同步=不变(代码逐行);滞后=delay+6帧(0.2s,否定/stamp/结论晚于旁白)

### 配色变量

**配色一律从 `references/theme-catalog.md` 选主题对象,不在本文件写死色板。** brief 的 themeRef 决定用哪个主题;没写默认 `block-frame`。

- 默认主题「block-frame」(新粗野):`BG=#FFFDF5`,`GRID=#F0EADF`,`INK=#000000`,`PALETTE=[#FE90E8, #C0F7FE, #99E885, #F7CB46, #FFDC8B]`,`ACCENT=[#000000]`
- 其他主题(creative-mode/scatterbrain/daisy-days/capsule/stencil-tablet):查 `theme-catalog.md` 取 BG/GRID/INK/PALETTE/ACCENT + lineConfig。

自定义色板规则:BG 与 GRID 明度差 10~15%;INK 与 BG 对比度 ≥7:1;PALETTE 给 4~6 个同明度、中低饱和色;ACCENT 给 1~2 个与 BG 强对比色。

### 动效变量(有默认值,一般不改)

- 弹入:spring damping=10~12,12~18 帧完成
- 转场重叠:18 帧(已就位元素保持静止,不呼吸不浮动)

## 设计基调(Token)

- 背景:BG 色 flat 底 + GRID 色网格线(可选,线宽 1.5px,间距约 80px)
- 描边:统一 INK 色,粗 3~4px(主题 lineConfig 定),**硬边直线,无圆润线端**
- 填充:只从 PALETTE 取色,纯色块无渐变
- 徽章:ACCENT 色底,只用于关键词/标题
- **硬偏移阴影**(贴纸的灵魂):`box-shadow: Npx Npx 0 INK`(或同色),零模糊,永远右下;偏移量 4/6/8/12/24px 按主题 lineConfig
- 文字:超粗无衬线(fontWeight 900),大写优先(block-frame/creative-mode);字色只用 BG 色(徽章内)或 INK 色(背景上)
- **色码贯穿**:同一概念全程用同一 PALETTE 色,不换色。开场为每个核心概念定一个色码,后续该概念再出现时用同色。

## 造型语法(五类内容构件 + 主题 signature 装饰层)

### 五类内容构件的画法语法(承载信息,唯一允许的信息容器)

> **不列组件名清单**——组件是工程资产(`src/components/sticker/`),skill 只定义"画法规则",按规则自由组合,别被清单框住实现。

1. **徽章**(承载关键词/标题):色块 + 超粗字(可方角或 pill,按主题 lineConfig),ACCENT 色底
2. **卡片**(承载一组相关图形):硬边容器(方角或固定圆角,按主题),带硬偏移阴影
3. **图形节点**(承载概念本体):矩形/圆/椭圆/圆柱拼出的示意图
4. **连接线**(表达关系/流向):直线或折线 + 末端实心小三角(实线 + 生长动画)
5. **背景网格**(唯一装饰层,可选):BG 色 flat 底 + GRID 色网格线

画法规则:2D 扁平、硬边(圆角 0 或主题 lineConfig 定的固定值)、纯色填充。
**禁渐变、禁模糊、禁 3D、禁 roughness(无手绘抖动)**。
**自由组合**:同一概念可以用任意几何形拼出来,不必局限于某个固定组件。

### 数据/ML 元素的画法约定(当内容需要时)

按内容语义自由画,给几个常见约定(非清单,可按需扩展):

- 表格/对比表:硬边网格表,表头 ACCENT 底,逐行弹入,可高亮某行
- 矩阵/热力图:格子矩阵,cell 填充透明度按 |值| 缩放,逐格 reveal
- 向量:一行带值的格子,标维度
- token 序列:一行圆点/方块,active 高亮放大,可画 attention 弧线
- 代码:卡片 + 等宽字体逐行点亮 + ACCENT 高亮条 + 讲完行回落
- 公式:拆成 token 按类型上色(var=PALETTE/num=ACCENT/fn=ACCENT2/op=INK)
- 对话:user 左/assistant 右气泡,硬边框 + 尾巴 + 角色标签
- 放大聚焦:把子元素放大推到中心 + 提层,聚焦后回落
- 粒子聚合:一组粒子先散布,再聚合到目标位

### 主题 signature 装饰层(只做静态陪衬,不承载信息)

从 `references/theme-catalog.md` 当前主题取 signature 元素(block-frame 倾斜装饰/creative-mode 色块排版/scatterbrain 图钉胶带/daisy-days 手绘装饰/capsule 药丸装饰/stencil 色块)。规则:

- **只做静态陪衬**:入场后不动、不参与信息表达、不与信息元素抢焦点
- **归属明确**:挂在角落/背景/卡片边缘,禁止盖在信息元件上
- **密度克制**:每屏 ≤3 处,多了变噪音
- **常见实现**(按主题,非清单):
  - block-frame 倾斜装饰:旋转 5~15° 的矩形/星形/徽章色块,硬边+硬阴影,静态破网格
  - creative-mode 色块排版:四色 flat 块本身就是 signature,不加层
  - scatterbrain 图钉:小圆(ACCENT 红)+ 小阴影,钉在卡片上角
  - scatterbrain 胶带:半透明浅色斜条(旋转 20~30°),跨卡片一角
  - daisy-days 手绘装饰:硬边版雏菊/星星/彩虹(SVG 路径),聚画面角落
  - capsule 药丸装饰:小号 pill 色块,散落背景,低饱和
  - stencil-tablet 色块排版:大地色块本身即 signature,不加层
- 主题没有 signature 就不加,不是每个主题都要有装饰

## AI 素材(交 asset-generation skill)

代码画不动的复杂插画(吉祥物/设备/有机曲线)、截图、Logo——**统一交给 `asset-generation` skill**(传 engine=sticker + themeRef)。判断标准/风格前缀/验收/接入规则都在那边,本文件不内嵌。工作流第 0.5 步先查 `public/` 现成素材,没有再调用。

## 动画语法(运动只有三种)

1. **弹入**(所有入场):回弹 spring,scale 0→1 带 overshoot + translateY 30→0 + 淡入
2. **信息密集推进**(anti-PPT 核心手段):已就位元素保持静止(不呼吸不浮动),靠每 1-2s 新元素入场/状态变化/焦点切换维持活力。不是"让东西一直动",是"让信息一直来"。
3. **转场**(导演标的类型为准,基础三式 + 高级四式):
   - **滑动**(推进):整组水平滑出/滑入,缓出曲线
   - **硬切**(紧迫):无过渡动画,直接切换场景
   - **淡入**(换话题):旧场景整体淡出,新场景淡入
   - **穿窗/虚焦接力/黑场字卡/甩镜**(高级,语义强):实现配方与命门见 `references/motion-recipes.md`——穿窗的窗几何与窗内景必须同一个 t 驱动,甩镜峰值速度 ≥300px/f 否则糊不透

**高级动效**(定格标注/变速/crash-zoom 急推/侧掠/缩放清晰度)的实现参数与命门统一见 `references/motion-recipes.md`;其中定格标注的圈注用硬边直角框+箭头(无手绘抖动),光效裁进硬边 overflow——本引擎的差分做法已在配方内标注。

细节:箭头用 `pathLength` 从起点向终点生长(贴纸风实线,不用虚线流动)。
禁止任何匀速线性动画。
**禁止装饰性运动**(呼吸/浮动/光球/火花/镜头无目的晃动)--对讲解无帮助,是噪音。

## 时序语法(与内容无关的铁律)

- 元素按阅读顺序逐个入场,永不一屏同时出现;相邻元素间隔 6~12 帧
- **入场三层顺序**:外框/容器先(定义空间)-> 核心元素次(填数据)-> 标签/箭头最后(标注关系)
- 节点先于连线(箭头等两端节点就位后才生长)
- 成组元素按行/列交错入场,组内间隔 3~5 帧
- **批量同类元素(≥5 个:矩阵格子/清单/卡片堆)用加速错峰**:间隔递减(如 8f→3f)+收尾静止 0.5s,可绑物理隐喻(发牌感);等间隔读作机械复读(配方见 `references/motion-recipes.md`)。固定间隔只用于异构信息的阅读顺序入场,不用于批量同类元素
- 已入场元素常驻不消失,直到整组转场
- 单场景时长:导演标的为准(3~8s),默认 3~5s

## 禁止项

- 五类内容构件禁止用图片代替,一律代码绘制;复杂插画允许 AI 生成素材,按上文「AI 素材生成」规则(锁色板、去文字、套统一弹入 hook)
- **禁渐变、禁模糊(含软阴影)、禁 3D**——阴影必须是硬偏移零模糊
- 禁细线(<2px)、尖角(除非主题是方角风格)、衬线字体
- 禁匀速动画、禁元素无故消失、禁一屏静态排版式出场
- 禁 `Date.now()`/`Math.random()`:伪随机一律固定种子(mulberry32/哈希,seed 从 index 派生),逐帧可复现——粒子聚合/散布、装饰散布全部种子化
- 禁在 theme 文件之外出现任何硬编码颜色值
- 禁装饰性运动(呼吸/浮动/光球/火花/镜头无目的晃动)

## 交付要求

- 配色集中为单一 theme 文件,全部从变量区映射;换主题只改 theme-catalog 条目
- 工程组件见 `src/components/sticker/`,按本文件画法规则使用;不硬套组件清单
- 统一弹入 hook(spring scale+位移+淡入)。已就位元素保持静止,不浮动
- 每个场景渲染关键帧静帧自检:布局居中、文字不裁剪、用色全部来自 PALETTE/ACCENT、阴影全是硬偏移零模糊
- 提供 dev 预览、stills、render 三个脚本
- **布局自检**(渲染静帧后程序化检查):bounding box 不重叠(引线/箭头除外)+ 在安全区内(四周边距≥80px,底部≥54px 字幕区)+ 文字不溢出容器。不通过则报具体碰撞对,定点修后重验
- **有效字高验收**:量渲染帧上的实际像素(fontSize × 祖先 scale × 透视压缩),字幕 ≥56px、辅助文字 ≥32px;brief 标 `(纹理)` 的字明显虚化/降亮度。文字只有两态:要读(达标)或纹理(淡化),无中间态(方法见 `references/motion-recipes.md`)
