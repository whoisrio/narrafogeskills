# 风格语法 · 像素风

写代码前读完本文件。所有颜色一律从当前主题取（`usePixel().palette`），正文和代码里不许出现硬编码色值。

> **与导演的边界**：导演定内容、相对布局、节奏、转场类型；本文件只定"怎么用像素画法实现它"。导演标的场景时长、转场类型、音画偏移以导演为准，本文件给的是实现默认值。

## 变量区

### 内容变量

- 主题：一句话说清这集讲什么
- 关键词：拆出的 3~8 个概念词
- 画幅：1920×1080 / 30fps（不换画布，换的是像素单位）
- 框架：Remotion + TypeScript，不引 rough.js、不引 spring
- 总时长：按导演的场景规划，单场景 3~8 秒

### 栅格变量（硬）

- `N = 5`：一个美术像素 = 5 个屏幕像素，逻辑画布 384×216
- 一切坐标写逻辑像素，过 `u()` 换屏幕像素；`u()` 只收非负整数，传 1.5 直接抛错
- 字号只有两档：`t = 12`（原生）、`T = 24`（整 2 倍），对应屏幕 60 / 120
- 动画帧步进 `HOLD = 2`：30fps 下每 2 帧一个动画帧，手感 15fps

### 配色变量

配色从 `references/theme-catalog.md` 选主题，不在本文件写死色板。brief 的 themeRef 决定用哪套，没写就用 `pico8`。

- `pico8`：PICO-8 官方 16 色，技术/机器/代码题材默认
- `cga`：IBM CGA 16 色，复古 PC、硬件、四位色对撞
- `db16`：DawnBringer 16，低饱和，适合长时间讲述

换主题只换 palette，组件不动。

## 设计基调

底是底色加 CRT 扫描线、1 格内框、四角加厚块，全部轴对齐矩形。面是 1 格硬边框的纯色块，没有圆角、没有阴影、没有半透明。字只有两档字号，靠位置和颜色阶分层。层次靠边框与底色阶做出来，不靠投影。

一屏最多两种强调色。三种以上就不叫强调了：观众不知道该看哪。

## 建构语法：六类图元 + 装饰层

像素风的信息容器只有这些。不要发明第七类。

`kit/` 里只提供会算错的那几样（`PixelText` / `Rects` / `Block` / `Bracket` / `Dotted` / `PixelSprite` / `gridCells` / `wire*`）。面板、底色、字幕带、HUD 自己写，规则在下面「自写组件」。

**1. 面板**：1 格边框 + 纯色底，装一组相关内容。边框占 1 格，内容要留 1 格内边距，否则字会贴边。

**2. 色块与条**（`Block`）：单块矩形。状态点、进度条、章节标记、分隔线都靠它。量小就用 Block，不必为一个矩形开 SVG。

**3. 阶梯线**（`wireRoute` / `wireDrop` / `growWire` / `dirArrow`）：横 → 竖 → 横，端点落在整数格。这是像素风的"线路板"语汇，表达流向和依赖。**永远不要用 SVG stroke 画线**：stroke 骑在 0.5px 上，5 倍放大后就是一条灰边。

**4. 括号与标记**（`Bracket` / `Dotted`）：八段实心条拼的选中框、抖点虚线。用来指认"这一段"，不要整块换色。

**5. 字符格**（`gridCells` + `PixelText`）：等宽格子铺开，画字节、矩阵、表格、指令行。像素风最擅长这个——所有字符天然对齐到格。

**6. sprite**（`PixelSprite`）：16×16 手绘图。规则见下。

**装饰层**：扫描线、内框、四角块、点阵（`DotField`）。只做静态陪衬，入场后不动，不承载信息，每屏不超过 3 处。

## 自写组件：四条硬约定

这四个不进库，因为都是"几个 div 加边框"，写起来没难度，但每条都有一个容易踩的点。

**面板**：`div` + `boxSizing: 'border-box'` + `border: u(1)px solid`。四条内边距的数字直接用这几个，不要凭感觉：小标题 `x+4 / y+3`，正文第一行 `x+4 / y+16`，左右各留 4 格，底部留 3 格。高度按内容算——标题一行 + 正文一行 = 32 格，每多一行正文加 14 格。**先算高度再画框**，反过来先画一个大框再往里填，底部一定会空出一大片。不要圆角、不要 `box-shadow`。

**底色**：一个 `svg`，`viewBox="0 0 384 216"` 配 `width/height 100%`，`shapeRendering="crispEdges"`。扫描线每 4 格一条、填 `panel` 色。内框用四条实心 `<rect>`，**不要用 `stroke`**。四角各一块 3×3。

**字幕带**：`position: absolute`，`left: u(28)`、`top: u(H-24-(行数-1)*14)`。两行上限，行高 14 格，一律左对齐，行首放 `▸`。逐字打出时不要居中——居中会让整行左右抖。

**HUD**：条高 12 格、间隔 4 格，列宽 `Math.floor((W - 32 - gap * (n - 1)) / n)`，**不要用 flex 平分**（浏览器自己取整，会落半格）。当前章填实色、其余填 `panel`，条下压一条 1 格高的进度线。

另外：整个像素层不要用 flex 做定位。绝对定位 + 显式整数坐标是唯一稳妥的写法。

## sprite 使用规则

sprite 是手画的图，不是形状，改不了尺寸和内容，所以它只能承担一件事：让人一眼认出"这是个具体的东西"。

- 只在这两种情况用：概念本身就是实体对象（文件、锁、芯片、手、机器人）；开场钩子需要一个大图标立住画面
- 抽象概念不要硬画成 sprite（"成本""杠杆""信任"这种），用面板 + 阶梯线 + 字表达
- 一个场景最多 1~2 个 sprite 当主角，其余全交给图元。满屏 sprite 会像贴纸册，信息密度反而下降
- 放大只能整数倍（1..5），没有 1.7 倍
- 换主题不改 sprite 数据：`ink` 存的是语义键（`edge`/`accent`/`bone`…），渲染时按当前主题解析

新画一张 sprite 的规矩：16×16，光从**左上**来，只用 `o b l s c` 五个字符，轮廓必须有 `o`——没有轮廓，深色主题下整张图会糊进底里。写完跑 `assertSprites()`，行数或格数不对会直接抛。

## 文字规则

- 字号只有 `t` 或 `T`。写 `fontSize: 48` 是错的；需要层次就用颜色阶、位置、边框、留白去做
- 对齐不用 CSS 的 `center`/`right`：文字宽度常是奇数，居中会落在半格上。用 `PixelText` 的 `align`，它内部把起始 x 吸到整数格再左对齐
- 布局宽度按 `estWidth()` 估算（全角 12、半角 6），不靠 `getBoundingClientRect()`——渲染期量不到，量到也会因字体加载跳
- 字幕最多两行，第二行不缩进
- 标点只用字体里有的。`≠`、`✓`、箭头符号会触发字体回退，回退出来的字形不是像素字，整格会糊——要画钩和叉，用 `Block` 拼

## 色彩规则

明暗只有阶，没有中间态。需要"淡出"就用调色板换一阶，或者抖点，不要用 alpha。

语义色一旦定下就全片不换：同一个概念始终同一个色。观众靠颜色认概念，中途换色就丢了锚点。调色板里 `code / data / os / protect / agent / evidence / unknown` 七个语义键就是为此准备的。

## 禁止项

`scripts/lint-pixel.mjs` 会扫源码，命中即失败。

| 禁止 | 原因 | 换成什么 |
| --- | --- | --- |
| `blur()` / `filter:` | 像素边缘被吃成灰边 | 抖点或硬边 |
| `linear-gradient` / `radial-gradient` | 平滑渐变等于抗锯齿 | 抖点（`ditheredIn`）或色阶 |
| `borderRadius` / `rx=` | 圆角不是像素语汇 | 直角 |
| `<circle>` / `strokeLinecap` | 圆弧会被抗锯齿 | 阶梯像素 / `Block` 拼 |
| `rgba()` / `opacity: 0.x` | 半透明不在有限调色板里 | 换色阶或抖点 |
| `spring()` / `Easing.` | 像素动画是逐帧步进 | `staged` / `blink` / `typewriter` |
| SVG `stroke` 当线用 | 骑在 0.5px 上，放大出灰边 | `wire.ts` 的实心矩形 |
| 手写 `fontSize` 数字 | 半档字号会把中文重新栅格化 | `t` / `T` |
| 外层 `scale(N)` 缩放 | GPU 采样会糊掉整幅 | 逐元素 `u()` |
| `≠ ✓` 等符号 | 字体回退撕碎栅格 | `Block` 拼或换说法 |

## 交付要求

- 组件从 `kit/` 引，颜色从主题取；换主题只改 `themeRef`
- 每个场景渲染静帧，跑 `check-pixel-frame.mjs`。判据两条：每 5×5 屏幕块同色；一帧色数很少（本引擎一般 9~17 色）
- 布局自检：元素 bounding box 不重叠（连线除外）、在安全区内、文字不溢出
- 有效字高：字幕就是 `t` 档的 60px。本引擎没有 32px 那档，别照搬别的引擎的"辅助 ≥32px"——那是给可变字号的引擎定的规则
