# 结构骨架（Templates）

参考，不是菜单。挑一个当起点，然后按内容改；不要为了"用上模板"把内容塞进不合身的骨架。

像素风的排版自由度比涂鸦/贴纸小：所有东西都是矩形和直线，所以骨架的选择基本决定了这一拍的观感。选错骨架，后面怎么调都像流程图。

## 1. 图标 → 字节（开场钩子）

左边一个 sprite 放大到 4 倍，右边一列字符格从它身上"抽"出来变成十六进制。用来开场点题：你以为看到的是一个东西，其实是一堆字节。

- sprite 走整数倍放大：1 → 2 → 4
- 字符格从 sprite 右侧 2 格处起，逐行 `typewriter`
- 最后一格高亮成 `accent`，停住

## 2. 面板 + 阶梯线（关系与流向）

最常用。三到五个面板，用 `wireRoute` 连起来，线上带 `dirArrow`。适合调用链、数据流、依赖关系、层级。

- 面板尺寸统一（写死整数），横向排布间距 ≥6 格
- 竖段错开，不要所有线都在同一列拐弯
- 连线在两端节点落位后才开始 `growWire`
- 超过 6 个节点就拆两屏，不要缩到看不清

## 3. 字符格矩阵（字节 / 数据 / 状态表）

`gridCells` 铺格子，每格一个字符。适合 hex dump、内存布局、真值表、权限位。

- 8~16 列，行数按内容定；列宽 = 全角字宽 12，行高 14
- 逐行 `typewriter`，或整格 `blink` 指认某一位
- 高亮用换色（`ash` → `accent`），不要加背景块

## 4. 对照双栏（前后 / 正反 / 有壳无壳）

左右两个面板，中间一条 `Dotted` 竖线。适合"原来 / 现在"、"公开 / 私有"、"结构 / 语义"。

- 两栏等宽，中间留 8 格
- 先左后右，右边入场时左边不动
- 中间竖线最后出现，1 格一节点亮

## 5. 阶梯堆栈（层级 / 栈帧 / 地址空间）

从下往上叠矩形，每层高度不同，左侧一行标签。适合内存布局、调用栈、分层架构。

- 底层最宽，向上收窄，宽度差 ≥8 格
- 每层落位后标签才出现（标签跟着层走）
- 指认某一层用 `Bracket`，不要整层换色

## 6. 时间轴 / 队列（顺序 / 并发 / 流水线）

一条横线贯穿，节点按时间落位，当前节点用 `Bracket` 圈住。

- 主轴 1 格高，节点 3×3 方块
- 节点间距相等时读作"节拍"，不等时读作"耗时"——按语义选
- 当前节点用 1 帧 `blink` 强调，不要做呼吸

## 7. 章首问题卡

全片唯一允许"一屏只有字"的节拍。左大字问题（`T` 档），右侧清单，底部游标闪。

- 停留 2~3 秒后压回顶部 HUD 条，不硬切
- 问题不超过两行，超过就不是问题了
- 清单 3~5 条，每条 ≤12 字

## 8. 常驻导航

顶部一排章节条 + 一条进度线。不承载信息，只回答"现在讲到哪"。长片（>2 分钟）必须有；短片可以省。

- 当前章填实色，其余填 `panel`
- 进度线推进取整，不要每帧 ±1px 地爬

## 选骨架的判据

- 这一拍要说的是"东西"还是"关系"？东西用 sprite + 面板，关系用阶梯线
- 有没有顺序？有就用时间轴，没有就用双栏/矩阵
- 观众需要记住的是"数量"还是"结构"？数量用字符格数得清，结构用堆栈看得见
- 一拍里超过 3 类图元就拆。像素风的画面容不下同时讲两件事
