# 运动配方库(Motion Recipes)

> **master**:本文件是 `narraforgeskills/skills/motion-recipes.md`。
> 各引擎 `references/motion-recipes.md` 是本文件的**逐字副本**——改配方只改 master,再同步各副本(同 theme-catalog 纪律)。
> **定位**:导演(visual-brief-design)给语义词,本文件给实现配方(参数/曲线/命门)。
> 风格无关;引擎差分在条目内标注,副本不做任何 per-engine 修改。
> **来源**:配方与判例迁移自 video-shotcraft(镜头配方卡 + 判例式审美准则),判例可信度来自真实返工记录。

## 入场

### 入场方式词表(与各引擎 SKILL.md 的出场方式对齐)

导演只写语义词，本表给默认实现。**这张表是唯一口径**：SKILL.md 里那句"出场方式 → 实现"的简写，以本表为准；两处不一致时改 SKILL.md，不要改这里。

| 词 | 语义 | 默认实现 | 参数 | 限制 |
| --- | --- | --- | --- | --- |
| `pop` | 元素出现 | spring 弹入：scale 0→1 带 overshoot + translateY 30→0 + 淡入 | damping 10~12，12~18f | 默认值。doodle 叠 ±1° 手摆；sticker 的硬阴影等落定后才出现，不跟着放大 |
| `slide` | 有方向地进入 | 沿方向 translate 滑入，缓出 | 14~18f，位移约 1/3 屏 | 方向必须与语义一致：输入从左侧来就 slide-left |
| `dissolve` | 换气 / 淡入 | opacity 0→1 + translateY 20→0 | 12~16f | **不加 blur**。要更"轻"就减小位移，不要加模糊 |
| `rush-in` | 突然杀到 | 高速位移 + 末帧 snap | 6~8f | 快段可包运动模糊，见「模糊的使用范围」 |
| `typewriter` | 逐字揭示 | clip 逐字展开 | 每字 1~2f | 光标只闪不抖 |
| `flip` | 翻面 | **平面翻转**：scaleX 1→0→1，中间换内容 | 各 6f | 透视翻转（rotateY）属 3D，只有 Seg 标 `维度:3D` 才允许 |
| `wipe` | 擦除揭示 | mask 沿方向推进 | 10~14f | doodle 用大圆角 clip，sticker 用直角 clip |
| `stagger` | 批量错峰 | 间隔递减 8f→3f，收尾静止 0.5s | 见下方 stagger 段 | 等间隔读作机械复读 |
| `blur-in` | 由虚变实 | opacity + blur 降 | 12~16f | **仅限标 `(纹理)` 的对象**；要读的元素不许用，改 `dissolve` |
| `draw` | 线条生长 | stroke 生长，箭头先长杆后出尖 | 按长度 12~20f | sticker 只长直线/折线，无抖动 |
| `scale-up` | 放大登场 | scale 0.8→1，ease-out | 12~16f | 禁匀速线性；起点不低于 0.6 |
| `rotate-in` | 旋转落定 | rotate -6°→0 同步淡入 | 12~16f | 限 2D，≤8°，不带透视 |
| `shimmer` | 扫光 | 一档更亮的**纯色**斜条扫过 | 8~10f | **禁渐变**：渐变扫光违禁。做不出纯色条就退化成 1 次高亮脉冲 |
| `snap` | 磁吸归位 | 越过目标 8~12px 后硬停 | 8~10f | 不带 spring 回弹，回弹就不是 snap |

规则：导演给的词落在本表里就照表做，不要自作主张换实现；表里标了「仅限」「禁」的，按标注执行并在交付说明里点名。导演给的词不在表里（引擎做不出的），用语义最近的替代，并同样点名。

pixel 引擎的逐词落地在 `pixel-explainer/references/motion-recipes.md` §1，那里有 5 个词做不出来、给了替代，不在本表范围。

### stagger 加速错峰(批量同类元素)

- 批量同类元素(≥5 个:矩阵格子/清单/卡片堆)入场用**间隔递减**的加速节拍(如 8f→3f),收尾静止 0.5s 再切下一拍。
- 可绑一个物理隐喻(发牌感):元素依次飞向自己的位置,归位越来越快。
- **命门**:等间隔读作机械复读,匀速读作廉价 PPT。
- 固定间隔只用于异构信息的阅读顺序入场(跟 cue 节奏),不用于批量同类元素。
- 判例:shotcraft R2——"卡片不断往下堆叠时,应该越来越快,并在最后停顿0.5秒";发牌隐喻一轮通过,抽象 flood 五轮不收敛。

### rush-in 疾冲入场

- 短时值(约 0.25s)+ 方向位移 + 末帧 snap;可选 `@remotion/motion-blur` 包冲刺段。
- 适用"突然杀到"的结论/冲击;方向必须与语义一致(来自左侧的输入用 slide-left,不是 rush-in)。

## 通用边界

### 模糊的使用范围（消解"禁模糊"与配方冲突）

各引擎 style-guide 的禁止项写着"禁模糊"，但配方里确实用到模糊。两者不矛盾，边界是：

- **元素层禁模糊**：形状、文字、卡片本体不许模糊，含软阴影、glow、虚化边框。
- **只在这三处允许**：① 镜头层运动模糊（`@remotion/motion-blur`，只在 rush-in / 变速的快段）；② 转场「虚焦接力」；③ 标 `(纹理)` 的文字虚化。
- 三处之外出现 blur，一律按违禁处理。

### 3D 的使用范围

透视、`rotateX/Y`、Three.js 只在 Seg 明确标 `维度:3D` 时允许；其余场合一律 2D 平面，`flip` 用 scaleX、`rotate` 用 Z 轴小角度。

## 强调

### 定格标注 freeze-annotate

- 帧号非线性 remap:流动 → 定格(斜率=0,**无缓入,定格要干脆**)→ 圈注 → 解冻(斜率>1 补偿时长)。
- 圈注:8f 描边划完(stroke-dashoffset),可配箭头 6f 点题;圈注 8f 淡出随解冻。
- **引擎差分**:doodle 用 feTurbulence(scale≈7)手绘抖动椭圆;sticker 用硬边直角框+箭头,无抖动;其他引擎按自家语汇落(暗金可光晕圈,现代 tech 可描边高亮)。
- **命门**:圈注太慢像加载动画;无抖动(doodle)像机械标注;目标对象必须锐利、居中(凝视对象不能糊)。
- **频率**:一支片 ≤2 次。
- 判例:shotcraft speed-ramp-freeze 卡——"停课划重点"。

### 变速 speed-ramp

- 快 → 慢窗 → 快:快慢斜率反差 **≥10 倍**才可感(慢窗 ≥40f);语义是"路过时多看一眼"。
- blur 联动速率:快段可包运动模糊、慢窗裸渲,"快糊-慢清"反差是手法成立的一半。
- 目标对象锐利居中。

### crash-zoom 急推

- 快速推近 + 冲击落定,配滞后音画偏移(旁白先说,视觉再砸)。
- 与"推近 push-in"(平滑、局部→细节的范围变化)区分:crash-zoom 是**节奏冲击**,不是范围变化;每场景 ≤1 次。

## 镜头

### 侧掠 side-glide(物动镜不动)

- 透视参数(perspective/origin/rotY)全程**常数**,唯一动的量是内容沿自身平面 translateX——内容像列车车厢依次掠过固定取景框。
- 2D 用 CSS perspective 模拟(非 3D 渲染)。
- **命门**:镜头一动语义就变成运镜炫技;这里的戏是"内容在自我展示"。
- 速度重影:拖尾层取过去时刻位置重投影,透明度 ∝ 滑移速度(快时浓);恒定重影读作重像故障。
- 适用 ≥3 屏宽的横排内容(长时间轴/长流程);与"横移 pan"(镜头动、内容静)正交,同段落二选一。
- 判例:shotcraft steep-tilt-glide 卡——"镜头是固定的,页面本身往其3d空间的横面方向移动"。

### 缩放清晰度(推近/放大的防糊技法)

- 放大量不走 `transform: scale`,走 CSS `zoom`(布局级缩放,让 Chromium 按放大后的设备尺寸栅格化,从高清源向下采样)。
- 位图(public/ 截图等)按显示尺寸 2~4 倍原生栅格化后缩小使用;关键被特写元素可单独更高倍。
- **排查顺序**:文字糊先查纹理分辨率链路(截图倍率 → 栅格化路径 → 缩放方式),最后才考虑其他——实证调相机治标无效。
- 判例:shotcraft Q2——用户三轮追打"文字还是不够高清",改 CSS zoom 推广到全部页面层才根治。
- 落了本配方:矢量元素推近不受 1.3x 限制;位图做过高清栅格化后也可超。

## 转场(高级四式;基础三式滑动/硬切/淡入在各引擎 style-guide)

### 穿窗 mask-wipe

- 页面内元素放大成全屏窗口,新场景从窗内长出接管;窗几何与窗内景**用同一个 t 同步驱动**(异步=穿帮)。
- 窗放大用 bezier 先慢后快;窗内新景从约 0.42 缩放反向补偿长到 1。
- **语义命门**:窗内新景必须是被点开元素的"详情世界"(概念总览 → 该概念深讲);塞无关场景=语义断裂,沦为花哨擦除。

### 虚焦接力 focus-handoff

- 前景滑出焦平面(blur 渐深)同时后景反向收焦入场,焦点当剪辑点。
- **两景错开 2~4f 起跑**——同帧起跑读作整屏糊掉;blur 交叉窗口 10~16f。

### 黑场字卡 black-card

- 前镜淡出 6~10f → 黑场字卡蓄力 → 淡入后镜 6~10f;章节级分段 + 呼吸位二合一。
- **频率**:一支 30s 片 ≤2 次,多了节奏碎。

### 甩镜 whip-pan

- 两端 hold ≥20f → 甩动 8f 跨约 1.5 屏 → 直接落位;峰值速度 ≥300px/f(不足则糊不透,露出换景穿帮)。
- 运动模糊只包甩动段(shutterAngle 200 / samples 8);两景同一水平线上拼接,甩完即停。

### 转场通用规则

- **一个接缝只用一式**,不叠加(暗场里再加白闪=穿帮)。
- **方向连续**:出与入同向,速度曲线连续不回摆;不接读作两条片子硬拼。
- **帧预算**:转场占用的帧从相邻镜头预算划走,同 hold 帧一样前置预留。

## 画质纪律

### 光效纪律

- glint/扫光/泛光**不群发**——批量元素入场靠运动本身,不靠逐个发光;一个镜头最多给主角一次。
- 光效必须被承载元素的边界裁剪:**doodle 裁进圆角 border-radius,sticker 裁进硬边 overflow**;光溢出边界是廉价感的典型来源。
- 判例:shotcraft Q4——"不需要每个卡片都闪烁一次"、"泛光划过的特效取消,不好看"。

### 有效字高

- 验收量**渲染帧上的实际像素**(fontSize × 全部祖先 scale × 透视压缩),不看代码里的 fontSize。
- 字幕有效字高 ≥56px(5.2% 帧高),辅助文字 ≥32px(3%);缩到 480px 宽模拟手机小窗复查。
- 文字只有两态:**要读**(达标字号 + 足够对比度)或**纹理**(明显虚化/降亮度让观众不去读),不存在"重排了但仍读不清"的中间态。
- 判例:shotcraft Q11——六处小字统一提到 60/40/34px 档后整改通过。

### 确定性渲染

- 禁 `Date.now()`/`Math.random()`;一切伪随机固定种子(mulberry32/哈希,seed 从 index 派生),逐帧可复现。
- 注意现有随机源:粒子聚合/散布、装饰散布、抖动相位——全部种子化。
